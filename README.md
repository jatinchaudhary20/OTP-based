# OTP-Based User Login

A full-stack OTP-based user authentication and checkout
application built with React, TypeScript, Express and
PostgreSQL.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Axios

### Backend
- Node.js
- Express
- TypeScript
- JWT
- bcrypt

### Database
- PostgreSQL
- Supabase

## Features

- User registration
- Six-digit OTP generation
- OTP-based login
- Email recognition
- JWT authentication
- Skip login option
- Checkout form
- PostgreSQL checkout storage

## Local Setup

### Backend

```Bash
cd backend
npm install
npm run dev
```

### Frontend

```Bash
cd frontend
npm install
npm run dev
```
