# AI Prompts Used

This project was developed with assistance from AI tools.

## Project Planning

Prompt:
"Break down this OTP-based user login assignment into
step-by-step implementation tasks."

## Backend

Prompt:
"Create an Express TypeScript registration API that accepts
email, first name and last name, generates a six-digit OTP,
hashes it and stores the user in PostgreSQL."

## Authentication

Prompt:
"Implement OTP verification using bcrypt and return a JWT
after successful authentication."

## Email Recognition

Prompt:
"Create an API endpoint that checks whether an email belongs
to a registered user."

## Frontend

Prompt:
"Create a React TypeScript checkout form with real-time email
recognition and an OTP modal."

## Checkout

Prompt:
"Create an Express API that stores checkout email, phone
number and shipping address in PostgreSQL."

## Debugging

Prompt:
"Debug the TypeScript/React/Express errors encountered
during development and explain the fixes."
